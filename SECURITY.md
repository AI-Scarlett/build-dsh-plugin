# Security

`dsh-build-plugin` is an isolated DSH Skill Provider adapter. Installing the Bundle only mounts the repository's `build-dsh-plugin/SKILL.md` and its bundled resources through `@deepseek-ai/dsh-skill-filesystem`.

The adapter does not install another Agent runtime, run lifecycle scripts, modify DSH source or official packages, disable official Skill providers, read credentials, access the network, or mutate a real Profile after package installation. Work generated by the Skill remains subject to the separate authorization and evidence gates documented inside the Skill.

Report suspected vulnerabilities through the repository's GitHub security reporting channel. Do not include credentials, private Profile contents, or full user files in a report.
